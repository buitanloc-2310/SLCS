# V42 — Assessment Governance

V42 separates three assessment surfaces: class assessment management for teachers/assistants, personal Assessment Center for candidates, and system-wide Assessment Administration for school/system admins.

Highlights: server-enforced restriction on system assessment types, canonical schedule state, question snapshots per attempt, blueprint/result-policy metadata, guest/internal attempts, administrative attempt operations with mandatory reasons and audit logs, question-bank/manual-grade counters, responsive candidate/admin UI, and unchanged Live/Media transport files.
